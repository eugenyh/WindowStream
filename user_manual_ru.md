# WindowStream — руководство пользователя

Это руководство описывает работу с **готовым исполняемым файлом `WindowStream.exe`**. Устанавливать Python и какие-либо библиотеки не нужно.

> **Язык интерфейса.** По умолчанию программа показывает английский интерфейс. Чтобы включить русский, откройте файл настроек (пункт меню «Open settings file») и задайте `"language": "ru"`, затем перезапустите программу. Названия пунктов меню в этой инструкции даны по-русски.

## 1. Что делает программа

WindowStream показывает **одно окно** с компьютера на экране другого устройства (планшета, телефона, другого компьютера) через обычный браузер. Картинка обновляется в реальном времени. Управлять окном с планшета нельзя: это только просмотр.

Как это устроено в двух словах: программа на ПК снимает содержимое выбранного окна и раздаёт его по локальной сети как видеопоток. На планшете вы открываете в браузере адрес компьютера, например `http://192.168.1.20:8080/`, и видите окно.

Программа работает в фоне и управляется значком в области уведомлений (рядом с часами).

## 2. Что нужно для работы

**На компьютере:**

- Windows 10 или 11, 64-разрядная.
- Файл `WindowStream.exe`. Ничего устанавливать не нужно.

**На планшете или другом устройстве:**

- Современный браузер (Chrome, Edge, Firefox и подобные).
- Подключение к **той же сети**, что и компьютер (обычно та же сеть Wi-Fi).

**В сети:**

- Роутер не должен запрещать устройствам обмениваться данными друг с другом (на роутерах эта функция часто называется «изоляция клиентов» или «AP isolation»).

## 3. Установка и первый запуск

### Установка

1. Создайте постоянную папку, например `C:\Tools\WindowStream\`, и скопируйте туда `WindowStream.exe`.
2. Не запускайте программу из папки «Загрузки» или из временных папок, особенно если планируете включить автозапуск: если файл потом переместят или удалят, автозапуск перестанет работать.

Отдельной установки нет: программа не записывает файлы в `Program Files` и не требует прав администратора.

### Первый запуск

1. Дважды щёлкните `WindowStream.exe`.
2. **Предупреждение SmartScreen.** Файл не подписан цифровой подписью, поэтому Windows может показать синее окно «Windows защитила ваш компьютер». Нажмите **Подробнее → Выполнить в любом случае**. Антивирус тоже может отреагировать на такой файл; если это произошло, добавьте программу в исключения.
3. **Запрос брандмауэра.** Windows спросит, разрешить ли программе доступ к сети. Отметьте **«Частные сети»** и нажмите **«Разрешить доступ»**. Без этого планшет не сможет подключиться. Публичные сети разрешать не нужно.
4. В области уведомлений появится серый значок (окно программы не открывается). Если значка не видно, нажмите стрелку **^ «Показать скрытые значки»** на панели задач. Чтобы значок был всегда на виду, перетащите его из этого списка на панель.

При первом запуске программа создаёт файл настроек (см. [раздел 9](#9-файл-настроек)).

## 4. Быстрый старт: пять шагов

1. **Запустите** `WindowStream.exe` и найдите значок в области уведомлений.
2. **Откройте окно, которое нужно показывать** (оно должно быть развёрнуто, не свёрнуто в панель задач).
3. Щёлкните значок **правой кнопкой мыши** → пункт **«Окно: не выбрано»** → выберите нужное окно в списке. Трансляция начнётся сразу, значок станет зелёным.
4. **Узнайте адрес:** наведите курсор на значок — во всплывающей подсказке будет адрес, например `http://192.168.1.20:8080/`.
5. **Введите этот адрес в браузере планшета.** Вы увидите окно с компьютера.

При следующем запуске программа сама вспомнит окно и начнёт трансляцию: повторно выбирать его не нужно.

## 5. Значок в области уведомлений

### Цвета значка

| Значок | Состояние |
| --- | --- |
| Серый круг с квадратом | Трансляция остановлена |
| Зелёный круг с треугольником | Идёт трансляция |
| Жёлтый круг с двумя полосками | Пауза |

### Подсказка

При наведении курсора на значок во время трансляции показывается, например:

```
Трансляция окна: идёт
Захват 10 к/с · новых кадров 3 к/с · клиентов 1
http://192.168.1.20:8080/
```

- **Захват** — сколько раз в секунду программа снимает окно.
- **новых кадров** — сколько изменившихся кадров в секунду отправляется. Если картинка в окне не меняется, здесь будет `0`. Это нормально: программа не отправляет одинаковые кадры, экономя процессор и сеть.
- **клиентов** — сколько браузеров сейчас смотрят трансляцию.
- Последняя строка — адрес для планшета.

Показатели обновляются раз в секунду. Если «Захват» заметно ниже заданной частоты кадров (по умолчанию 10), значит, компьютер не успевает: уменьшите частоту, масштаб или качество (см. [раздел 9](#9-файл-настроек)).

## 6. Меню значка

Меню открывается **правой кнопкой мыши** по значку.

| Пункт | Что делает |
| --- | --- |
| **Начать трансляцию** | Запускает трансляцию выбранного окна. Доступен, когда трансляция остановлена. |
| **Пауза / Продолжить** | Приостанавливает и возобновляет трансляцию. На планшете остаётся последний кадр с пометкой «Пауза». Название пункта меняется в зависимости от состояния. |
| **Закончить трансляцию** | Полностью останавливает трансляцию и закрывает подключения. Планшет покажет «Нет связи». |
| **Окно: …** | Открывает список окон, доступных для трансляции. Текущее окно отмечено. Выбор окна сохраняется и сразу запускает трансляцию этого окна. |
| **Вывести окно на передний план** | Разворачивает окно (если оно свёрнуто) и выводит его поверх остальных. |
| **Запускать вместе с Windows** | Включает и выключает автозапуск (галочка показывает, что он включён). |
| **Открыть файл настроек** | Открывает файл настроек в Блокноте. |
| **Выйти** | Останавливает трансляцию и закрывает программу. |

Недоступные в данный момент пункты неактивны (серые).

## 7. Выбор окна для трансляции

### Как выбрать

Правая кнопка по значку → **«Окно: …»** → выберите окно из списка.

Что происходит при выборе:

1. окно запоминается (заголовок и имя программы, которой оно принадлежит);
2. если окно было свёрнуто, оно разворачивается, затем выводится на передний план;
3. трансляция перезапускается на новом окне, на экран выводится уведомление с адресом.

В списке показываются обычные окна программ (до 40 штук, по алфавиту). Не показываются: окна командной строки и терминала, рабочий стол, служебные и скрытые окна, а также очень маленькие окна. Если нужного окна нет в списке, убедитесь, что оно открыто и не свёрнуто, и откройте меню заново: список составляется при каждом открытии.

### Как программа находит окно потом

Программа запоминает **заголовок** окна и **имя файла программы** (например, `myapp.exe`). При поиске окна используются такие правила по порядку:

1. заголовок совпадает полностью;
2. заголовок начинается с сохранённого текста;
3. заголовок содержит сохранённый текст;
4. если ничего не подошло, но имя программы известно — берётся **самое большое видимое окно этой программы**.

Благодаря четвёртому правилу трансляция не теряется, когда заголовок окна меняется. Например, в заголовке многих программ есть имя открытого файла, и при открытии другого файла заголовок становится другим.

Чтобы всегда транслировать окно, даже если заголовок меняется, можно указать в настройках только часть заголовка (например, название программы без имени файла): см. параметр `title` в [разделе 9](#9-файл-настроек).

### Окно закрыто или ещё не открыто

- Если окно закрыть во время трансляции, программа ищет его снова и продолжит показ, когда оно появится.
- Если окно не открыто при запуске программы (например, сразу после входа в Windows), программа выведет уведомление «Окно … не найдено. Жду появления окна...» и будет проверять каждые 5 секунд, пока оно не появится.

## 8. Просмотр на планшете

### Как открыть

1. Убедитесь, что планшет подключён к той же сети, что и компьютер.
2. В браузере планшета введите адрес из подсказки значка, например `http://192.168.1.20:8080/`. Адрес начинается с `http://` (не `https://`).
3. Страницу удобно добавить в закладки.

### Как узнать адрес, если подсказка показывает неподходящий

В подсказке выводится наиболее подходящий адрес, но у компьютера может быть несколько сетевых подключений. Чтобы увидеть все адреса:

1. нажмите `Win + R`, введите `cmd`, нажмите Enter;
2. выполните команду `ipconfig`;
3. найдите **IPv4-адрес** подключения, через которое компьютер связан с планшетом (обычно начинается с `192.168.` или `10.`).

Адреса, начинающиеся с **`169.254.`**, — служебные: Windows назначила их сама, не получив адрес от роутера. Они работают только если у планшета тоже адрес из этого диапазона. Обычно при таком адресе нужно проверить подключение к сети.

Порт (`8080`) можно изменить в настройках.

### Что видно на странице

Картинка окна вписана в аккуратную рамку со скруглёнными углами на весь экран браузера, с сохранением пропорций. Название вкладки браузера совпадает с заголовком транслируемого окна и обновляется вместе с ним.

**Индикатор режима в правом верхнем углу:**

| Индикатор | Значение |
| --- | --- |
| Зелёная мигающая точка, **Транслируется** | Идёт трансляция. Рядом показывается `N fps · M мс`: сколько новых кадров в секунду получает планшет и приблизительная задержка. |
| Жёлтая точка, **Пауза** | На компьютере включена пауза. Картинка замерла и потускнела. |
| Красная точка, **Нет связи** | Компьютер недоступен или трансляция остановлена. Картинка серая, поверх неё крутится индикатор. Страница переподключается сама, обновлять её не нужно. |

Цвет тонкой подсветки по краю рамки тоже соответствует режиму (зелёный, жёлтый, красный).

**Автоскрытие.** Во время обычной трансляции индикатор и кнопки исчезают через 4 секунды, чтобы не закрывать картинку. Коснитесь экрана, чтобы показать их снова. Во время паузы и при потере связи они остаются на экране постоянно.

### Управление жестами

| Действие | Результат |
| --- | --- |
| Касание | Показать индикатор и кнопки |
| Два пальца (сведение и разведение) | Масштабирование до ×8 |
| Один палец при увеличении | Перемещение картинки |
| Двойное касание | Приблизить в 2,5 раза в этой точке, повторное двойное касание возвращает исходный вид |
| Касание метки `×2.4 · сброс` (справа внизу) | Сбросить масштаб |
| Долгое нажатие (около 0,7 с) | Скрыть или показать строку `fps · мс`. Выбор запоминается в браузере |
| Кнопка в левом верхнем углу | Полноэкранный режим |
| Колесо мыши (на компьютере) | Масштабирование |

Метка масштаба справа внизу появляется, пока картинка увеличена, и остаётся видимой.

> Совет: при увеличении картинка остаётся такой же чёткой, как передаётся с компьютера. Для чёткого увеличения оставьте `scale` равным `1.0` (это значение по умолчанию).

### Несколько устройств

К одной трансляции можно подключить несколько устройств одновременно: число подключений показывается в подсказке значка («клиентов»).

## 9. Файл настроек

### Где находится

```
%APPDATA%\WindowStream\settings.json
```

Обычно это `C:\Users\<имя пользователя>\AppData\Roaming\WindowStream\settings.json`.

Проще всего открыть его из меню значка: **«Открыть файл настроек»** (откроется в Блокноте). Файл создаётся автоматически при первом запуске.

> **Изменения вступают в силу после перезапуска программы.** Закройте её через **«Выйти»** и запустите снова.

Выбранное в меню окно сохраняется в файле автоматически (параметры `title` и `process`).

### Пример

```json
{
  "title": "Untitled - Map",
  "process": "mapapp.exe",
  "port": 8080,
  "fps": 15.0,
  "quality": 75,
  "scale": 1.0,
  "mode": "printwindow",
  "no_diff": false,
  "no_turbo": false,
  "autostart_broadcast": true,
  "language": "en"
}
```

Соблюдайте формат JSON: строки в двойных кавычках, между параметрами запятые, после последнего параметра запятой нет, `true` и `false` пишутся строчными буквами без кавычек. Если файл повреждён, программа его проигнорирует и использует значения по умолчанию. Тогда исправьте файл или удалите его: при следующем запуске он создастся заново.

### Параметры

| Параметр | По умолчанию | Описание |
| --- | --- | --- |
| `title` | пусто | Заголовок окна или его часть (регистр не важен). |
| `process` | пусто | Имя файла программы, которой принадлежит окно (например `mapapp.exe`). Помогает найти окно, когда заголовок меняется. Заполняется автоматически при выборе окна из меню. |
| `port` | `8080` | Порт, по которому доступна трансляция. Меняйте, если порт занят другой программой. |
| `fps` | `10` | Максимальное число кадров в секунду (не меньше 0,5). Чем больше, тем плавнее и тем выше нагрузка. |
| `quality` | `75` | Качество JPEG от 1 до 95. Больше — чётче, но тяжелее для сети. |
| `scale` | `1.0` | Масштаб передаваемого кадра (не меньше 0,1). `0.5` — вдвое меньше по каждой стороне. |
| `mode` | `"screen"` | Режим захвата: `"screen"` или `"printwindow"` ([раздел 10](#10-режимы-захвата-screen-и-printwindow)). |
| `no_diff` | `false` | `true` — отключить проверку изменений и отправлять каждый кадр (повышает нагрузку, обычно не нужно). |
| `no_turbo` | `false` | `true` — не использовать быстрый кодировщик JPEG (нужно только для сравнения). |
| `autostart_broadcast` | `true` | `false` — не начинать трансляцию сразу после запуска программы, а ждать команды «Начать трансляцию» в меню. |
| `language` | `"en"` | Язык интерфейса: `"en"` — английский (по умолчанию), `"ru"` — русский. Влияет на меню в трее, уведомления, сообщения в консоли, `--help` и страницу на планшете. После изменения перезапустите программу. |

### Рекомендуемые значения

| Ситуация | Настройки |
| --- | --- |
| Обычный просмотр карты | по умолчанию (`fps` 10, `quality` 75, `scale` 1.0) |
| Слабый Wi-Fi или слабый планшет | `fps` 10–15, `quality` 60–70, `scale` 0.75 |
| Максимальная чёткость, много увеличения | `scale` 1.0, `quality` 80–90, `fps` 10 |
| Плавное движение | `fps` 20–30 (нагрузка на компьютер выше) |
| Меньше нагрузка на компьютер | `fps` 5–10, `scale` 0.5–0.75 |

Если картинка в окне не меняется, программа почти не нагружает компьютер и сеть — это делает проверка изменений кадра, включённая по умолчанию.

## 10. Режимы захвата: screen и printwindow

Параметр `mode` определяет, как программа получает картинку окна.

| | `screen` (по умолчанию) | `printwindow` |
| --- | --- | --- |
| Принцип | Копирует прямоугольник окна с экрана | Просит само окно нарисовать своё содержимое |
| Другие окна поверх нужного | **Попадают в трансляцию** | Не попадают |
| Окно закрыто другими окнами | Видно то, что сверху | Транслируется нормально |
| Программы с GPU-отрисовкой (карты 3D, видео, игры) | Работает | У некоторых программ картинка чёрная или устаревшая |
| Свёрнутое окно | Не транслируется | Не транслируется |

**Как выбрать:**

1. Сначала попробуйте `"printwindow"`. Если картинка правильная — оставьте этот режим: другие окна перестанут попадать в трансляцию.
2. Если картинка чёрная или не обновляется, вернитесь к `"screen"`. В этом режиме держите окно на переднем плане и следите, чтобы его ничего не закрывало. При выборе окна из меню программа сама выводит его на передний план, а пункт **«Вывести окно на передний план»** делает это в любой момент.

Транслируется всегда **рабочая область окна** (без заголовка окна и рамок), в реальном размере в пикселях.

## 11. Запуск с параметрами

Обычно параметров в командной строке не нужно: всё хранится в файле настроек. Но при желании можно запускать программу с ключами.

### Как запустить из командной строки

Откройте командную строку в папке с программой и введите, например:

```
WindowStream.exe --title "Untitled - Map" --mode printwindow --save
```

### Ярлык с параметрами

1. Щёлкните `WindowStream.exe` правой кнопкой → **Отправить → Рабочий стол (создать ярлык)**.
2. Щёлкните ярлык правой кнопкой → **Свойства**.
3. В поле **Объект** после пути к файлу добавьте параметры через пробел, например:
   `"C:\Tools\WindowStream\WindowStream.exe" --port 9000`

### Список ключей

| Ключ | Описание |
| --- | --- |
| `--title "текст"` | Заголовок окна или его часть. |
| `--list` | Показать список открытых окон (описатель, программа, заголовок) и выйти. |
| `--port N` | Порт (по умолчанию 8080). |
| `--fps N` | Максимум кадров в секунду (по умолчанию 10). |
| `--quality N` | Качество JPEG 1–95 (по умолчанию 75). |
| `--scale X` | Масштаб кадра, например `0.5` (по умолчанию 1.0). |
| `--mode screen` / `--mode printwindow` | Режим захвата. |
| `--no-diff` | Отключить проверку изменений кадра. |
| `--no-turbo` | Не использовать быстрый кодировщик JPEG. |
| `--no-autostart` | Не начинать трансляцию при запуске, ждать команды из меню. К автозапуску Windows этот ключ отношения не имеет. |
| `--config "путь"` | Использовать другой файл настроек. |
| `--save` | Сохранить параметры этого запуска в файл настроек. |
| `--help` | Справка по ключам. |

**Приоритеты.** Ключи командной строки главнее файла настроек, но сами по себе в файл не попадают, если не указать `--save`. Ключи-переключатели (`--no-diff`, `--no-turbo`) можно только включить; чтобы выключить такой параметр, измените файл настроек.

### Список окон

Собранная программа не имеет собственного окна консоли, поэтому `--list` и `--help` выводят текст в **ту командную строку, из которой запущены**:

```
WindowStream.exe --list
```

Если запустить эту команду двойным щелчком, текст показать некуда.

## 12. Запуск вместе с Windows

### Как включить

Правая кнопка по значку → **«Запускать вместе с Windows»**. Рядом с пунктом появится галочка. Повторный выбор пункта выключает автозапуск.

Автозапуск включается только для вашей учётной записи и не требует прав администратора.

### Что происходит при входе в Windows

1. Программа запускается в фоне, в области уведомлений появляется значок.
2. Если в настройках задано окно и `autostart_broadcast` равен `true`, программа начинает трансляцию.
3. Если окна ещё нет (например, нужная программа тоже запускается), программа ждёт его и проверяет каждые 5 секунд, а затем начинает трансляцию сама.

Если окно в настройках не выбрано, программа только выведет подсказку выбрать окно в меню значка.

### Если файл переместили

Если вы перенесли `WindowStream.exe` в другую папку и запустили его оттуда, программа сама обновит путь в автозапуске. Если вы удалили файл, не отключив автозапуск, Windows при входе не найдёт программу; чтобы убрать запись, снова запустите программу из любой папки и отключите автозапуск в меню.

## 13. Пауза, остановка и выход

| Действие | Что происходит | Что видит планшет |
| --- | --- | --- |
| **Пауза** | Съёмка окна приостанавливается, программа продолжает работать | Последний кадр, метка «Пауза» |
| **Продолжить** | Съёмка возобновляется | Живая картинка |
| **Закончить трансляцию** | Съёмка и раздача прекращаются, порт освобождается, значок серый | «Нет связи», страница сама подключится, когда вы снова начнёте трансляцию |
| **Выйти** | Программа полностью закрывается | «Нет связи» |

Если окно свернуть, картинка на планшете останавливается на последнем кадре, пока окно не развернут. Программа при этом продолжает работать.

## 14. Несколько трансляций одновременно

По умолчанию можно запустить только **одну копию** программы: при повторном запуске появится сообщение «Программа уже работает» с подсказкой найти значок возле часов, и вторая копия закроется. Порт при этом не затрагивается.

Чтобы транслировать несколько окон одновременно, запустите копии с **разными файлами настроек и разными портами**:

```
WindowStream.exe --config "D:\ws\first.json" --port 8080 --title "Окно 1" --save
WindowStream.exe --config "D:\ws\second.json" --port 8081 --title "Окно 2" --save
```

На планшете откройте разные адреса: `http://192.168.1.20:8080/` и `http://192.168.1.20:8081/`. Оба порта нужно разрешить в брандмауэре, а автозапуск будет работать для той копии, из которой вы его включили.

## 15. Обновление и удаление

### Обновление

1. Закройте программу: правая кнопка по значку → **«Выйти»**.
2. Замените `WindowStream.exe` новой версией в той же папке.
3. Запустите её. Настройки сохранятся, они хранятся отдельно от программы.

Если автозапуск был включён, он продолжит работать (путь остаётся прежним).

### Полное удаление

1. Отключите автозапуск: правая кнопка по значку → снимите галочку **«Запускать вместе с Windows»**.
2. Закройте программу пунктом **«Выйти»**.
3. Удалите `WindowStream.exe`.
4. При желании удалите папку настроек `%APPDATA%\WindowStream\` (введите этот путь в адресной строке Проводника).

## 16. Безопасность

- Трансляция **не защищена паролем и не шифруется**. Любой, кто подключён к вашей сети и знает адрес, может посмотреть содержимое окна.
- Используйте программу только в доверенных сетях (домашняя или рабочая сеть, к которой подключены только свои устройства). В общедоступных сетях (кафе, гостиницы) её не используйте.
- В брандмауэре разрешайте доступ только для **частных сетей**.
- Не транслируйте окна с конфиденциальными данными, если в сети есть посторонние.
- Для доступа из другой сети используйте VPN. Не открывайте порт программы в интернет.
- Планшет не может управлять компьютером через эту программу: это только просмотр.

## 17. Сообщения программы

Собранная программа не показывает консоль, поэтому сообщения выводятся как уведомления Windows возле часов.

| Сообщение | Значение и что делать |
| --- | --- |
| **Трансляция запущена. Откройте на планшете: …** | Всё хорошо, откройте указанный адрес на планшете. |
| **Окно «…» не найдено. Жду появления окна...** | Нужное окно не открыто. Откройте его: трансляция начнётся сама. Или выберите другое окно в меню. |
| **Окно не выбрано: выберите его в меню трея** / **Выберите окно в меню иконки: пункт «Окно»** | В настройках нет окна. Выберите окно в меню значка. |
| **Не удалось открыть порт 8080: …** | Порт занят другой программой или другой копией. Смените `port` в файле настроек. |
| **Транслируется: …** | Трансляция переключена на выбранное окно. |
| **Программа будет запускаться вместе с Windows** / **Автозапуск отключён** | Результат переключения автозапуска. |
| **Не удалось изменить автозапуск: …** | Запись в реестре недоступна (например, запрещена политикой организации). Обратитесь к администратору. |
| **Не удалось открыть файл настроек: …** | Блокнот не запустился. Откройте файл вручную (см. [раздел 9](#9-файл-настроек)). |
| Окно «**Программа уже работает**» | Копия программы уже запущена. Найдите её значок возле часов, возможно, в скрытых значках. |

## 18. Устранение неполадок

| Проблема | Возможная причина и решение |
| --- | --- |
| Планшет не открывает страницу | 1) Планшет и компьютер в разных сетях — подключите к одной. 2) Брандмауэр блокирует доступ — разрешите программу для частных сетей (Пуск → «Разрешение взаимодействия с приложением через брандмауэр»). 3) Неверный адрес — проверьте его командой `ipconfig` (см. [раздел 8](#8-просмотр-на-планшете)). 4) Роутер включил изоляцию клиентов — отключите её. 5) Адрес начинается с `169.254.` — проверьте подключение к сети. |
| Значок не виден | Нажмите стрелку **^** («Показать скрытые значки») на панели задач и перетащите значок на панель. |
| Программа не запускается, ничего не происходит | Возможно, она уже работает: значок может быть среди скрытых. Попробуйте запустить ещё раз: если появится сообщение «Программа уже работает» — она запущена. |
| SmartScreen или антивирус блокирует файл | Файл не подписан. Нажмите «Подробнее → Выполнить в любом случае» либо добавьте файл в исключения антивируса. |
| Поверх нужного окна видны другие окна | Режим `screen` копирует изображение с экрана. Установите `"mode": "printwindow"` в настройках либо держите нужное окно на переднем плане. |
| Картинка чёрная | Окно рисуется через GPU и не отдаёт содержимое режиму `printwindow`. Установите `"mode": "screen"`. |
| Часть окна не обновляется | Эта часть находится за краем экрана: Windows и программа её не перерисовывают. Сдвиньте окно так, чтобы оно целиком помещалось на экране, или используйте второй монитор. |
| Картинка замерла, а индикатор «Транслируется» | Окно свёрнуто. Разверните его или выберите **«Вывести окно на передний план»**. |
| В подсказке «новых кадров 0 к/с» | Картинка в окне не меняется. Это нормально. |
| После смены окна на планшете осталась старая картинка | В режиме `screen` новое окно может оказаться за другими окнами. При выборе окна из меню оно теперь выводится на передний план автоматически; если нет, используйте пункт **«Вывести окно на передний план»**. |
| Высокая нагрузка на процессор | Уменьшите `fps`, поставьте `scale` 0.5–0.75, уменьшите `quality`. |
| Картинка дёргается или запаздывает | Слабый Wi-Fi или слабый планшет: уменьшите `scale` и `quality`; по возможности подключитесь к сети 5 ГГц. Смотрите на планшете задержку в мс и в подсказке значка частоту захвата. |
| Задержка на планшете показывается как «—» | Это нормально в первые секунды после подключения. |
| Трансляция не запускается после входа в Windows | Нужное окно ещё не открыто (программа его ждёт) либо окно не выбрано в настройках — выберите его в меню значка. |
| Окно программы, запущенной от имени администратора, не транслируется | Запустите WindowStream тоже от имени администратора (правая кнопка по файлу → «Запуск от имени администратора»): Windows не позволяет обычным программам управлять окнами с повышенными правами. |
| Настройки не действуют | Изменения вступают в силу после перезапуска программы. Также проверьте формат файла (запятые, кавычки): при ошибке файл игнорируется. |
| Файл настроек нужно сбросить | Закройте программу, удалите `%APPDATA%\WindowStream\settings.json` и запустите снова. |

## 19. Ограничения

- Транслируется одно окно на одну копию программы.
- Нет звука.
- Нет управления с планшета: только просмотр.
- Показывается только рабочая область окна (без заголовка и рамок).
- Свёрнутое окно не транслируется: на планшете остаётся последний кадр.
- Часть окна за краем экрана не обновляется.
- В режиме `printwindow` некоторые программы с GPU-отрисовкой дают чёрную картинку; видео, защищённое от копирования, не показывается ни в одном режиме.
- Нет пароля и шифрования (только обычный `http://`).
- Интерфейс программы и страницы — на английском или русском языке (параметр `language`).

## 20. Частые вопросы

**Нужен ли интернет?**
Нет. Достаточно локальной сети между компьютером и планшетом. Интернет для работы программы не используется.

**Можно ли смотреть с телефона или другого компьютера?**
Да. Подойдёт любое устройство с современным браузером в той же сети.

**Сколько устройств может смотреть одновременно?**
Несколько. Число подключений видно в подсказке значка.

**Программа закрывает окно или мешает работе в нём?**
Нет. Она только снимает содержимое окна. Работать в нём на компьютере можно как обычно. Единственное действие с окном — вывод его на передний план при выборе из меню или по пункту «Вывести окно на передний план».

**Что будет, если закрыть окно, которое транслируется?**
Программа продолжит работать и найдёт окно снова, когда оно появится. На планшете до этого будет последний кадр.

**Что будет, если заголовок окна поменялся?**
Программа найдёт окно по имени программы (самое большое окно этой программы). Название вкладки на планшете обновится.

**Как сменить порт?**
Измените `port` в файле настроек и перезапустите программу. На планшете используйте новый адрес, например `http://192.168.1.20:9000/`.

**Почему адрес в подсказке отличается от того, что я ожидал?**
Компьютер может иметь несколько сетевых адаптеров (Wi-Fi, Ethernet, виртуальные). Выберите с помощью `ipconfig` адрес того подключения, через которое компьютер связан с планшетом.

**Где посмотреть текущую версию настроек и что в них можно менять?**
Пункт меню **«Открыть файл настроек»** и [раздел 9](#9-файл-настроек).

**Как остановить программу совсем?**
Правая кнопка по значку → **«Выйти»**. Простое закрытие окна не нужно: у программы нет окна, только значок.
